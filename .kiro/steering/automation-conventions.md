# Automation conventions for this repository

Follow the binding rules in `docs/conventions.md` for every change to this test framework: reuse existing code first, menu-based folders, one page object per screen, run-time generated data through `src/gridzee_qa/utils/data_generator.py`, the Admin test pattern, the safety rules, and the documentation updates. Run tests only with the user's permission.
